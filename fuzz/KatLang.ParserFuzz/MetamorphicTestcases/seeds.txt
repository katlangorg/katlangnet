# Curated metamorphic seed corpus (KATLANG_FUZZ_MODE=metamorphic).
#
# A metamorphic seed is a TEMPLATE PAYLOAD, not a KatLang source file: the two programs a
# case compares are regenerated deterministically from these bytes by the same decoder and
# template the fuzzing loop uses, so nothing here duplicates source text.
#
# Line format (fields in this order; `desc` is optional and runs to end of line):
#   family=<relation-family-id> bytes=<hex payload> desc=<human-readable note>
#
# COMMON payload prefix (bytes 0-5) — unchanged since Phase 1:
#   0 relation family        [dotted-collection-call, dotted-collection-builtin,
#                             user-extension-call, dotted-chain, builtin-callback-wrapper,
#                             optimizer-generic-parity, cached-property-reuse,
#                             entry-point-parity, budget-law, spread-spelling-parity]
#   1 legacy range stop      [1, 0, 2, 3, 5, 8, -1, -3, 16, 33, 64, 100]  (Phase 1 family only)
#   2 limit mode             Phase 1 family: [Default, CumulativeItems, PerCollectionItems, Both]
#                            Phase 2:        + [CumulativeStrings, PerStringLength, Generous]
#                            Phase 3:        each family declares its own subset; budget-law
#                                            declares the single FamilyDerived mode
#   3 primary limit offset   [-1, 0, +1, +4]   (relative to the MEASURED total the mode bounds;
#                                               for budget-law it is the BOUNDARY offset)
#   4 secondary limit offset [-1, 0, +1, +4]
#   5 optimizer              [on, off]  (normalized away where a family fixes the policy)
# APPENDED family dimensions (bytes 6+), never an overload of an existing byte:
#   dotted-collection-builtin: 6 builtin, 7 receiver shape, 8 suffix variant
#   user-extension-call:       6 body template, 7 receiver shape, 8 suffix variant
#   dotted-chain:              6 chain template, 7 receiver shape
#   builtin-callback-wrapper:  6 consumer, 7 callback builtin, 8 input shape, 9 wrapper projection
#   optimizer-generic-parity:  6 source template, 7 execution order
#   cached-property-reuse:     6 value/use template, 7 reuse count, 8 execution order
#   entry-point-parity:        6 source template, 7 surface pair, 8 execution order
#   budget-law:                6 source template, 7 law, 8 resource dimension, 9 isolation mode
#   spread-spelling-parity:    6 spread-slot context, 7 operand shape
#
# BACKWARD COMPATIBILITY: a payload of six bytes or fewer is a version-zero payload and always
# decodes to the Phase 1 family with the Phase 1 tables, exactly as it did before Phase 2.
#
# Replay:  dotnet run --project fuzz\KatLang.ParserFuzz -- metamorphic-replay fuzz\KatLang.ParserFuzz\MetamorphicTestcases
