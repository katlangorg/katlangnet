# Tracked editor-tooling fuzz seeds (Phase 7).
#
# An editor seed is a TEMPLATE PAYLOAD, not a source file: the payload selects a trusted editor
# template plus difficult UTF-16 code units, a cursor placement and a bounded edit, and the harness
# regenerates the exact source deterministically. Storing source text would rewrite an isolated
# surrogate to U+FFFD, so the manifest is pure ASCII and carries the 13-byte payload in hex.
#
# The declared template is redundant on purpose: replay checks it against the template the payload
# decodes to, so a stale seed is reported instead of quietly replaying a different case.
#
# Payload layout (one byte each): template, surface, injGroup, injMember, placement, lineEndings,
# execution, cursor, cursorBias, edit, editGroup, editMember, editBias.
#
# There is deliberately NO completion or active-parameter signature-help seed: neither surface exists
# in KatLang.Semantics, so cases that would target them use the nearest real surface (position
# resolution, property/signature metadata) instead.

template=comment-only bytes=02 01 00 00 00 00 00 0B 00 00 00 00 00 desc=comment, cursor inside the comment
