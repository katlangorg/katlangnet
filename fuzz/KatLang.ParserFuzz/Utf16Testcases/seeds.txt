# Curated UTF-16 seed corpus (KATLANG_FUZZ_MODE=utf16).
#
# A UTF-16 seed is a TEMPLATE PAYLOAD, not a KatLang source file. That is not a stylistic
# preference: an isolated surrogate has NO UTF-8 form, so a seed stored as source text would be
# rewritten to U+FFFD by git, by an editor, or by File.ReadAllText, and would silently stop testing
# the thing it names. This manifest is therefore pure ASCII and carries the payload in hex; replay
# feeds it to the same decoder, builder and executor the fuzzing loop uses.
#
# Line format (fields in this order; `units` and `desc` are optional, `desc` runs to end of line):
#   template=<template-id> bytes=<hex payload> units=<hex code units> desc=<note>
#
# `template` is redundant on purpose: it is checked against the template the payload decodes to.
# `units` pins the EXACT code-unit sequence the payload must build, in four-digit hex — the
# round-trip guard for the seeds whose whole point is one difficult code unit.
#
# PAYLOAD LAYOUT (frozen; see Utf16Decoder):
#   0 template   1 placement   2 line-ending mode   3 execution mode
#   4 group      5 member      6 repeat             7 filler
#   8+ raw tail  (only the two raw templates read it)
