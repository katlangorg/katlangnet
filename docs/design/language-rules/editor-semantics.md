## Scope visibility and module provenance

Scope visibility is completion's semantic source: `SemanticModel.ScopeVisibilities` / `GetVisibleSymbolsAt` and `PreludeCatalog` must enumerate exactly what ownership-first lookup resolves — same shadowing, open dedup, same-level open ambiguity suppression, and direct-beats-open prelude precedence as `ElaboratedScopeLookup`. Scope regions are source-span hulls. MODULE PROVENANCE: a load-elaborated module subtree (`Algorithm.User.IsModuleElaborated`, set by `ModuleLoader` on the spliced root) is module-provided at EVERY nesting depth — nested algorithms, clause families, inline open-target blocks, and modules the module opens included — because its spans belong to the module's source text, so the semantic model emits NO document-owned sites for it (no scope regions, declaration occurrences, reference sites, or identifier-classification sites; every site the model lists slices the current document to the identifier written there) while still building its scopes and symbols for binding. A document reference to an imported member classifies normally (`PropertyReference`, `OpenTarget`) with a LOCATIONLESS target: `ResolvedDeclaration`, `PropertyInfo.Declaration`, parameter spans, clause-head spans, and `VisibleSymbol.Declaration` are null (the existing no-local-location convention — never a fabricated or module-relative span), and the imported `PropertyInfo` enters `PropertyInfos` only through such a document site. Provenance is STRUCTURAL, decided per owner before the walk (`ModuleProvidedAlgorithmCollector`): lookups create property symbols lazily and a body analyzed before `M = load('url')` can reach a nested module algorithm through `open M.Sub` before the walk enters the module, so the walk position alone cannot classify an owner; the region stack's inherited suppression is that set's walk-time projection and gates every site the walk creates. Host-built DAGs may share module source anchors under document-owned parents: `ModuleProvidedAlgorithmCollector` also records those spans by REFERENCE IDENTITY, and every site/metadata factory filters them (equal coordinates from distinct sources stay independent). A local property reusing an imported body keeps its own declaration but no imported parameter spans; locationless real symbols still participate in direct lookup/completion precedence. Suppression follows module provenance, never the mere presence of an `open`: document-owned inline `open { ... }` blocks, ordinary nested algorithms, and local content after an imported open keep every site (private members included), imported public names stay visible through the open, private ones never leak, and deferred module regions (B2c, below) are unaffected. Cross-file navigation into module text is not provided. Builtin names/signatures for editors come from `PreludeCatalog`, never hardcoded lists. Inside a deferred module region (B2c) the semantic model performs NO module I/O and never asserts that a module-supplied name is invalid: a name that resolves nowhere lexically under a deferred module open, a member of an unmaterialized `X = load('url')` placeholder, and an implicit parameter a nested body inferred provisionally there classify `IdentifierClassification.DeferredModuleReference` (indeterminate until the branch is selected), while names outside that lookup chain, ambiguous opens, open heads, explicit parameters, and binders keep their ordinary classification.
