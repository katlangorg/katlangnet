## Scope visibility and module provenance

Scope visibility is completion's semantic source: `SemanticModel.ScopeVisibilities` / `GetVisibleSymbolsAt` and `PreludeCatalog` must enumerate exactly what ownership-first lookup resolves — same shadowing, open dedup, same-level open ambiguity suppression, and direct-beats-open prelude precedence as `ElaboratedScopeLookup`. Scope regions are source-span hulls. POSITIONS AND SITES (Task 3b): every position query — `FindResolutionAt`, `FindPropertyAt`, `FindScopeAt`, `GetVisibleSymbolsAt` — takes a `SourcePosition` (1-based line and UTF-16 column), never an integer pair, and every site or hull is a half-open `SourceSpan`: a site contains its first column and NOT the column just past its last character (`abc` at column 1 is `[1:1, 1:4)`; the cursor at column 4 is outside it), a scope hull is the `Union` of the extents it saw, and listings are ordered by `Start` then `End` (`SpanComparer`, an ORDERING distinct from value equality — equal coordinates never merge two sites). A locationless target is a `null` declaration or span, never a default span. MODULE PROVENANCE: a load-elaborated module subtree (`Algorithm.User.IsModuleElaborated`, set by `ModuleLoader` on the spliced root) is module-provided at EVERY nesting depth — nested algorithms, clause families, inline open-target blocks, and modules the module opens included — because it is the module's LOCATIONLESS import view (`ModuleLoader.ToImportView`: no node inside it carries a source span), so the semantic model emits NO document-owned sites for it (no scope regions, declaration occurrences, reference sites, or identifier-classification sites; every site the model lists slices the current document to the identifier written there) while still building its scopes and symbols for binding. A document reference to an imported member classifies normally (`PropertyReference`, `OpenTarget`) with a LOCATIONLESS target: `ResolvedDeclaration`, `PropertyInfo.Declaration`, parameter spans, clause-head spans, and `VisibleSymbol.Declaration` are null (the existing no-local-location convention — never a fabricated or module-relative span), and the imported `PropertyInfo` enters `PropertyInfos` only through such a document site. Provenance is STRUCTURAL, decided per owner before the walk (`ModuleProvidedAlgorithmCollector`): lookups create property symbols lazily and a body analyzed before `M = load('url')` can reach a nested module algorithm through `open M.Sub` before the walk enters the module, so the walk position alone cannot classify an owner; the region stack's inherited suppression is that set's walk-time projection and gates every site the walk creates. Host-built DAGs may move imported nodes under document-owned parents: they carry no spans, so they anchor no site and need no provenance bookkeeping of their own (the former by-reference span set is gone — nothing in the model depends on `SourceSpan` object identity). A property is synthetic (hidden from completion and member listings) by STRUCTURE — the hoisted deconstruction source — never by the absence of declaration spans, which an imported declaration also lacks. A local property reusing an imported body keeps its own declaration but no imported parameter spans; locationless real symbols still participate in direct lookup/completion precedence. Suppression follows module provenance, never the mere presence of an `open`: document-owned inline `open { ... }` blocks, ordinary nested algorithms, and local content after an imported open keep every site (private members included), imported public names stay visible through the open, private ones never leak, and deferred module regions (B2c, below) are unaffected. Cross-file navigation into module text is not provided. Builtin names/signatures for editors come from `PreludeCatalog`, never hardcoded lists. Inside a deferred module region (B2c) the semantic model performs NO module I/O and never asserts that a module-supplied name is invalid: a name that resolves nowhere lexically under a deferred module open, a member of an unmaterialized `X = load('url')` placeholder, and an implicit parameter a nested body inferred provisionally there classify `IdentifierClassification.DeferredModuleReference` (indeterminate until the branch is selected), while names outside that lookup chain, ambiguous opens, open heads, explicit parameters, and binders keep their ordinary classification. RECOVERY PLACEHOLDERS DECLARE NOTHING (final audit, September 2026): the only spanless explicit parameter a `ParseResult` can hold outside a module-provided subtree is the parser's recovery binder for a malformed binding pattern (`F(*) = …` keeps its slot with a unique, unwritable synthetic name rather than capturing a real `_error_` name); it is not source-backed, so `SemanticModelBuilder.CreateScope` declares no symbol for it — it never surfaces in completion, never classifies a reference, and never registers a declaration (`SemanticModelTests.RecoveryPlaceholderParameter_NeverSurfacesAsAVisibleSymbol`). Equality-transparent `IsRecoveryPlaceholder` metadata on the binder and its parameter declaration distinguishes missing slots from imported, locationless real names; ordinary and conditional signature displays retain the missing slot as `?`; conditional binder-name lists contain written binders only. Imported, locationless parameters retain their real names.

SCOPE VISIBILITY IS A VIEW, NOT A SNAPSHOT (FE-4b, September 2026; C# editor representation, no Lean counterpart). Scope visibility may share immutable persistent representation. Sharing never changes visible contents, declaration identity, shadowing, ambiguity suppression, or ordinal-name enumeration. S scopes seeing V names have S � V logical memberships without requiring S independent V-entry snapshots. Scope-local additions and shadows retain only changed tree paths. Explicit enumeration remains proportional to logical output; indexing and name lookup follow one tree path, independent of lexical nesting depth. Treap balance is expected under randomized per-process name hashes, not a deterministic worst-case guarantee. Exact ordinal-name tie-breaking keeps shape canonical even when priorities collide; node interning compares symbol, deferred twin, metadata, and child references after hash bucket selection.

Each frame derives visibility from its parent: open decisions never override direct names anywhere in the chain (including the prelude), ambiguity removes an outer open name, then parameters and first non-synthetic properties apply, with same-level parameters winning. Shared open layers include the parent tree, ordered provider target identities, and outer deferred-level count. FE-3 template-table reuse includes deferred classification and is invalidated by a direct override. Read-time deferred twins retain the chain's synthetic-name shielding. Build-local caches, frames, pending registration worklists, and interners are not retained by the public view. `RegisterVisibleMetadata` preserves the old visibility pass's declaration-registration side effects at the original scope-emission boundary, consuming shrinking metadata worklists instead of constructing visibility snapshots. This preserves tied-span host-AST declaration/resolution order, including the first result of a position query.

PUBLIC CONTRACT: nonempty `ScopeVisibility.Symbols` remains a distinct `ReadOnlyCollection<VisibleSymbol>` wrapper per scope; empty scopes keep the shared empty array. Scope record equality, `with` clones, and text remain compatible. All mutation routes reject writes; generic and non-generic enumeration reject `Current` outside a valid item and support reset. `SyncRoot` is stable for each public list and `IsSynchronized` remains false; its identity relative to the wrapper is an implementation detail, not a lock shared across scopes. One immutable `VisibleSymbol` object is reused for the same symbol within a model. This is a deliberate behavioral change: `ReferenceEquals` becomes true across those scopes, and member-bearing symbols that previously differed solely by copied `Members` wrappers now compare equal and hash consistently. Generated record equality still compares the public fields and collection identities; it is not a general declaration-identity comparator. Distinct declarations are never interned merely by name. Implicit FE-3 parameters without source declarations can share a template symbol; this does not merge owner or runtime identities. Distinct symbols can also share immutable member backing behind distinct constant-size `Members` wrappers; the public constructor still snapshots host-supplied lists. This removes the host-alias � member-width retained-array product without changing member-wrapper equality. A new model has its own symbols. Completion reads the shared view plus an unshadowed prelude tail without caching a flat scope snapshot.

`ScopeVisibilityRepresentationTests`, `Fe4bHostileReviewTests`, and non-friend `ScopeVisibilityPublicContractTests` pin structural sharing, eager/dictionary oracles, collisions, insertion order, declaration targets, deferred classification, template invalidation, lifetime, ordering, enumeration state, and public compatibility. The census measures shared-subtree height independently of traversal order. `ComputeEagerReferenceSymbols` remains a test-only oracle. Sharing `ResolvedOpenProvider` public-member indexes per target is a separate follow-up and is not implemented by FE-4b.
