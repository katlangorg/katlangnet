# Language rules — the detail behind `AGENTS.md`

`AGENTS.md` keeps a compact index of the rules so that it stays short enough to load on every request. The files in this directory hold the full statement of each rule — consequences, examples, the implementation map, and the pinning tests. The detail moved here verbatim from `AGENTS.md` in September 2026; in November 2026 the dense statements `AGENTS.md` still carried moved here too, as the **Summary** list that opens a section (its items cite rules by the names of the `AGENTS.md` index). They are as binding as `AGENTS.md`; an index entry there ends with a pointer such as ``[`syntax.md` § The spread marker]`` naming the section here.

Use the table to find the sections that state the rules of the subsystem you are about to change, and read them — including their **Summary** lists — BEFORE changing it. Keep them in step: a rule change edits the index entry, the section's summary and its full statement together, and deletes the text it supersedes. A new rule gets a section in the file of its subsystem and one entry in the `AGENTS.md` index; a new subsystem also gets a row in the table below (`AGENTS.md` § Keeping the system description current).
